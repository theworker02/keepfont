# keepfont

Keep numeric font values, ranges, and human-readable units.

**Site:** https://theworker02.github.io/keepfont/

## Install / run

```bash
git clone https://github.com/theworker02/keepfont.git
cd keepfont
node src/cli.js
node --test
```
